Next.js is a powerful React framework that makes building full-stack web applications a breeze.

## Why Next.js?

- **Server Components** — render on the server for better performance
- **File-based Routing** — intuitive page structure
- **Built-in Optimizations** — images, fonts, and more

### App Router vs Pages Router

The App Router (introduced in Next.js 13) is the recommended way to build new applications:

| Feature | App Router | Pages Router |
|---------|-----------|--------------|
| Server Components | ✅ | ❌ |
| Layouts | ✅ | ❌ |
| Streaming | ✅ | ❌ |

> Next.js 16 continues to improve the App Router experience with better performance and developer tools.

Start building today!
