Tailwind CSS v4 brings a lot of exciting changes to the utility-first CSS framework.

## What's New in v4

The latest version is built on a completely rewritten engine that's faster and more powerful.

### Key Features

1. **CSS-first configuration** — use native CSS instead of JavaScript config
2. **Improved performance** — incremental builds are lightning fast
3. **New utilities** — more design tools out of the box

Here's a simple example:

```html
<div class="flex items-center gap-4 rounded-xl bg-white/40 p-6 backdrop-blur-md">
  <h2 class="text-2xl font-bold">Hello, Tailwind!</h2>
</div>
```

### Glassmorphism Pattern

Combining `backdrop-blur`, semi-transparent backgrounds, and subtle borders creates a beautiful glass effect that works great with dark backgrounds.
